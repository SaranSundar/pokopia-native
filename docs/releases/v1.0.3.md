**Fixes for the Mac installer and the shader refresh.**

## What's new in 1.0.3

- **The Mac app no longer closes without a word (#4).** It logs the builder window to `~/Library/Logs/pokopia-native/builder.log` (with your Python, Tk and macOS versions first), and if the window stops with an error or crashes, a dialog shows the end of that log. Attach the log to an issue if you need help; it holds no game files.
- **`refresh` tells you when setup is missing (#5).** A new download or a copy of pokopia-native in another folder needs `nxs2.py setup` once (it builds the shader tools); `refresh` used to stop with a traceback about `ampere-lower` instead of saying so. Your build folders keep working.

To update: download this release (or `git pull`). If it's a new folder, run **Setup** once there.

## This version at a glance

- **Devices:** Mac and iPhone.
- **Controls:** drag to look (Mac and iPhone).
- **Builder and saves:** built from your own dump; the iPhone app from a Mac or a Windows PC.
