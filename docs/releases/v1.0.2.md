**App icon and launcher fixes.**

## What's new in 1.0.2

**Pokopia Native Builder.app** now opens on the Mac: its launcher was stored without the executable permission, so macOS said the app "can't be opened" and the builder only ran from Terminal. Includes the icon fix from v1.0.1.

A copy downloaded with a browser is still blocked the first time, because the app is not signed by a registered developer: try to open it, then System Settings → Privacy & Security → **Open Anyway**. A git clone opens directly.

Already have a copy? `chmod +x "Pokopia Native Builder.app/Contents/MacOS/launcher"` in the folder makes it open, or download this release.

## This version at a glance

- **Devices:** Mac and iPhone.
- **Controls:** drag to look (Mac and iPhone).
- **Builder and saves:** built from your own dump; the iPhone app from a Mac or a Windows PC.
