**An app icon fix.**

## What's new in 1.0.1

Fixes icons, Pokédex pictures and habitat pictures showing another item's picture after the store or Pokédex had been opened (#1).

To update: download this release (or `git pull`), run **Setup** again, then **Build** with the same settings (only the app is rebuilt, a few minutes), sign it and install it over the old app. Your save stays.

## This version at a glance

- **Devices:** Mac and iPhone.
- **Controls:** drag to look (Mac and iPhone).
- **Builder and saves:** built from your own dump; the iPhone app from a Mac or a Windows PC.
