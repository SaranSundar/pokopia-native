# Provenance and clean-room log

This project is MIT-licensed. Its code is written from public documentation, from permissively licensed projects (credited
below and in the code where used), and from our own work (pokopia-native, nxnative, which is MIT).

## Never read the source of

drakolordx7/pokopia-recomp, drakolordx7/nxrecomp (both GPL-3.0), yuzu, Eden, suyu, Citron, Sudachi, Unicorn, QEMU.
Their issue trackers, release notes and Markdown documentation may be read (milestone 1 did: see `research/01-their-issues.md`).
